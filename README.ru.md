# Sector 43 Clans

[English](README.md) | **Русский**

Лёгкий серверный мод кланов для **NeoForge 26.1.2**, сделанный для Minecraft-сервера Sector 43.

Игроки создают клан, выбирают тег и цвет и зовут друзей. Тег клана стоит перед ником, а сам ник красится в цвет клана. Это видно над головой, в табе и в чате. Мод работает на ванильных командах scoreboard, поэтому **игрокам ничего ставить не нужно**.

```
[СЕК] Alice    ← тег в цвете клана, ник тоже цветной
```

## Возможности

- Клан создаётся одной командой. Тег по умолчанию берётся из названия.
- Свой тег (буквы и цифры, кириллица поддерживается) и любой из 16 ванильных цветов.
- Приглашения с ограниченным сроком, выход, исключение, передача лидерства и роспуск с подтверждением.
- `/clan info` и `/clan list`, чтобы посмотреть кланы.
- Кто может создавать кланы, решают права, поэтому работает с **LuckPerms**. Например, создавать кланы разрешено только VIP и выше.
- Админская команда, чтобы распустить любой клан.
- Кланы сохраняются вместе с миром и переживают перезапуск.
- Серверный конфиг: длина названия и тега, лимит участников, окраска ника, friendly fire и срок приглашения.
- `/resize`: игроки с правом меняют свой рост (ванильный атрибут `minecraft:scale`), как плагин ResizePlayers.

## Требования

| | |
|---|---|
| Minecraft | 26.1.2 |
| NeoForge | 26.1.2.126 или новее |
| Java | 25 |
| Сторона | только сервер (у клиентов может стоять, но не обязательно) |
| Необязательно | [LuckPerms](https://luckperms.net/) для управления правами |

## Установка

1. Скачай `sector43clans-<версия>.jar` из [Releases](https://github.com/sheynor43/sector43-clans/releases).
2. Положи его в папку `mods/` на сервере.
3. Запусти сервер. При первом запуске появится конфиг `world/serverconfig/sector43clans-server.toml`.
4. Выдай право на создание кланов (см. [Права](#права)).

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/clan` или `/clan help` | все | Список команд |
| `/clan create <название>` | `sector43clans.create` | Создать клан, ты становишься лидером |
| `/clan tag <тег>` | лидер | Сменить тег клана |
| `/clan color <цвет>` | лидер | Сменить цвет (`red`, `gold`, `aqua`, `dark_purple`…) |
| `/clan invite <игрок>` | лидер с правом `sector43clans.invite` | Пригласить игрока, который сейчас онлайн |
| `/clan accept` | приглашённый | Принять последнее приглашение |
| `/clan decline` | приглашённый | Отклонить приглашение |
| `/clan leave` | участник | Выйти из клана. Если лидер остался в клане один, клан распускается |
| `/clan kick <игрок>` | лидер | Исключить участника |
| `/clan transfer <игрок>` | лидер | Передать лидерство другому участнику |
| `/clan disband` | лидер | Просит подтверждения. Распустить: `/clan disband confirm` |
| `/clan info [название]` | все | Информация о твоём или указанном клане |
| `/clan list` | все | Все кланы на сервере |
| `/clan admin disband <название>` | `sector43clans.admin` | Распустить любой клан |
| `/resize` | `sector43clans.resize` | Показать свой рост |
| `/resize <рост>` | `sector43clans.resize` | Изменить рост в блоках (обычный — 1.8, пределы в конфиге) |
| `/resize reset` | `sector43clans.resize` | Вернуть обычный рост |
| `/resize <рост> <игрок>` | `sector43clans.resize.others` | Изменить рост другому игроку |

Игрок может состоять только в одном клане. Лидер не может выйти, пока в клане есть другие участники: сначала нужно передать лидерство или распустить клан.

## Права

Мод регистрирует права через Permission API NeoForge, поэтому ими управляет LuckPerms (или другой мод прав). Если право не задано, оно есть только у операторов сервера.

| Право | По умолчанию | Что даёт |
|---|---|---|
| `sector43clans.create` | операторы | Создание кланов |
| `sector43clans.invite` | операторы | Приглашать в свой клан |
| `sector43clans.admin` | операторы | Команды `/clan admin` |
| `sector43clans.resize` | операторы | `/resize` для себя |
| `sector43clans.resize.others` | операторы | `/resize` для других игроков |

Пример для LuckPerms, чтобы кланы могли создавать только VIP и выше:

```
/lp group vip permission set sector43clans.create true
/lp group vip permission set sector43clans.invite true
/lp group vip permission set sector43clans.resize true
/lp group admin permission set sector43clans.admin true
```

Группы, которые наследуют `vip`, получат право автоматически.

## Настройки

`world/serverconfig/sector43clans-server.toml`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `nameMinLength` / `nameMaxLength` | 3 / 16 | Длина названия клана |
| `tagMinLength` / `tagMaxLength` | 2 / 5 | Длина тега |
| `maxMembers` | 0 | Лимит участников вместе с лидером. `0` значит без лимита |
| `colorNames` | true | Красить ник в цвет клана. Если `false`, цветным будет только тег |
| `friendlyFire` | true | Могут ли участники клана бить друг друга |
| `inviteTimeoutSeconds` | 300 | Сколько секунд действует приглашение |
| `resizeMinHeight` / `resizeMaxHeight` | 1.3 / 2.5 | Пределы роста для `/resize` в блоках |

## Как это устроено

- Данные кланов хранятся в `world/data/sector43clans/clans.dat`.
- Каждому клану соответствует ванильная команда scoreboard `s43clan_N`. Её префикс показывает тег, а цвет команды красит ник. При каждом запуске сервера команды синхронизируются заново.
- Не меняй команды `s43clan_*` через `/team`: мод перезапишет их при следующей синхронизации.
- Моды на чат (например, FlectonePulse) могут заменять ванильный формат сообщений. Если тег не виден в чате, добавь префикс команды игрока в формат сообщений этого мода.

## Сборка из исходников

```bash
git clone https://github.com/sheynor43/sector43-clans.git
cd sector43-clans
./gradlew build
```

Готовый jar будет в `build/libs/`. Java 25 Gradle скачает сам через toolchain.

Запустить локальный тестовый сервер с модом: `./gradlew runServer`. Перед этим нужно принять Minecraft EULA в `run/eula.txt`.
